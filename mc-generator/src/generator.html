1 設定練習參數 / Configuration

2 貼上題庫文本 / Paste Question Data

Excel 格式說明： 請在 Excel 中依序安排欄位： A:題目, B:選項A, C:選項B, D:選項C, E:選項D, F:標準答案(A/B/C/D), G:解析(選填)。 複製所有資料列（請勿包含標題列），直接貼上到上方區塊。

3 生成與匯出 / Export

產生器會將題庫與選定模式編譯入一個單一且離線可用的 HTML 檔案中。

Google Sites 嵌入步驟指引

1

輸入資料並下載檔案

設定好本科科名、練習標題、作答模式、配色，並貼上 Excel 複製之題庫後，點擊「下載獨立 HTML 檔案」取得 .html 檔。

2

複製 HTML 代碼

用電腦內置的「記事本」(Notepad) 或文字編輯器開啟下載的 .html 檔案，按下 Ctrl + A 全選，再按下 Ctrl + C 複製全部內容。

3

在 Google Sites 嵌入

打開您的 Google Sites 協作平台編輯介面。點擊右側面板的「插入」 > 「嵌入 (<>)」。

4

貼上程式碼

在彈出的視窗中切換到「嵌入程式碼」分頁，將剛才複製的程式碼貼入，點擊「下一步」並按「插入」。

5

拖曳調整版面

拖曳調整嵌入區塊的大小，使其完美符合測驗高度。發佈網頁，即可與學生分享！
