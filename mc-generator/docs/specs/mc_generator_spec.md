# 📝 MC Generator 設計規格書 (Product Specification)

## 1. 專案背景與目標
為了讓不具備程式背景 (No-coding base) 的教師能為學生快速製作美觀、實用且支援多語系的選擇題測驗，本專案將開發一個「MC 選擇題測驗網頁產生器」。
教師只需在 Excel 編輯題目，複製貼上至網頁中，即可一鍵下載包含所有題庫與樣式的獨立 HTML 檔案，並透過簡單的指引將其嵌入 Google Sites。

---

## 2. 產生器功能規格 (Generator Specs)

### 2.1 步驟一：參數設定區 (Configuration)
此區域為第一步，教師在此設定測驗的基本屬性。這些屬性將影響後續步驟的輸入欄位以及最終生成的網頁樣式。
- **科目名稱 (Subject)**: 文字輸入框，例如：「化學科」、「S3 Mathematics」。
- **練習標題 (Title)**: 文字輸入框，例如：「期中溫習練習」、「Ch.1 Quiz」。
- **匯出檔案名稱 (File Name)**: 文字輸入框，用以指定導出之 HTML 檔名。預設與「練習標題」內容同步聯動，亦支援教師手動自訂修改。
- **學生作答模式 (Quiz Mode)**: 下拉選單，包含：
  1. **一次顯示全部 (Show All Questions)**: 預設模式，所有題目以垂直滾動卡片列表同屏展示。
  2. **一題一頁模式 (One Question per Page)**: 每次只顯示一個題目卡片，答對提交後點選「下一題」按鈕始跳轉至下一題。
  3. **隨機抽 10 題模式 (Random 10 Questions)**: 從題庫中隨機洗牌抽取 10 題（若總題數不足 10 題則取全部）進行單題分頁測驗。
- **主題顏色 (Theme Color)**: 提供 4 種預設的主題色選項，並在介面上顯示色彩預覽：
  1. **科技藍 (Sky Blue)**: 主色 `#0284c7` (Sky-600), 背景漸層 `#f0f9ff` (Sky-50)
  2. **經典綠 (Classic Green)**: 主色 `#16a34a` (Green-600), 背景漸層 `#f0fdf4` (Green-50)
  3. **活力橘 (Vibrant Orange)**: 主色 `#ea580c` (Orange-600), 背景漸層 `#fff7ed` (Orange-50)
  4. **優雅紫 (Elegant Purple)**: 主色 `#7c3aed` (Violet-600), 背景漸層 `#f5f3ff` (Violet-50)
- **語系模式 (Language Mode)**: 下拉選單，包含：
  1. **繁體中文 (Traditional Chinese)**: 預設 UI 為中文，僅顯示「中文題庫輸入區」。
  2. **English (英文)**: 預設 UI 為英文，僅顯示「英文題庫輸入區」。
  3. **中英雙語切換 (Bilingual Switch)**: 最終產出網頁包含「中/英切換按鈕」，此時產生器介面將開啟「中文題庫輸入區」與「英文題庫輸入區」兩個獨立的貼上區。

### 2.2 步驟二：題庫輸入區 (Question Input)
根據語系模式的選擇，動態調整輸入區域：
- **Excel 貼上格式 (TSV 支援)**:
  教師在 Excel 中選取並複製 A 到 G 欄的資料（排除標題列），直接貼上至 Textarea。
  - Excel 欄位對應關係：
    - **A 欄**: 題目內容 (Question)
    - **B 欄**: 選項 A (Choice A)
    - **C 欄**: 選項 B (Choice B)
    - **D 欄**: 選項 C (Choice C)
    - **E 欄**: 選項 D (Choice D)
    - **F 欄**: 正確答案 (Ans) — 容許值：`A`, `B`, `C`, `D`（不分大小寫，或支援中文 `A.`, `B.` 等容錯處理）
    - **G 欄**: 題目解析/詳解 (Explanation)
  - **動態欄位顯示**:
    - **繁體中文 / 英文**: 顯示單一 Textarea。
    - **中英雙語切換**: 顯示左/右或上/下兩個 Textarea，分別為「貼上中文題庫」與「貼上英文題庫」。產生器會依據列數 (Index) 一對一配對（例如：中文題庫的第 1 題配對英文題庫的第 1 題）。
- **語法容錯與解析邏輯**:
  - 以換行符 (`\n`) 分隔每一題。
  - 每行以 Tab 字元 (`\t`) 分隔欄位。
  - 自動過濾空白行與前後空白字元。
  - 當點擊下載或預覽時，若發現中英文題數不一致，將提示警告訊息。

### 2.3 步驟三：匯出與 Google Sites 嵌入 (Export & Embed Guide)
- **匯出選項**:
  1. **複製嵌入碼**: 提供一個 `<iframe>` 嵌入語法。由於 Google Sites 嵌入 HTML 可以直接貼上代碼，我們將主要推薦「下載獨立 HTML 檔案」，然後在 Google Sites 中使用「嵌入 > 嵌入程式碼」並直接貼上 HTML 代碼，或者將 HTML 上傳至 Google Drive 後進行嵌入。
  2. **下載獨立 HTML 檔案**: 點擊按鈕，瀏覽器自動打包並下載 `[練習標題].html` 檔案。
- **Google Sites 嵌入指引**:
  - 以精美圖文步驟卡片形式展示：
    1. 在產生器點擊「下載獨立 HTML 檔案」。
    2. 開啟 Google Sites 編輯頁面。
    3. 在右側面板選擇「插入」 > 「嵌入 (< >)」。
    4. 選擇「嵌入程式碼」，將下載的 HTML 檔案內容以文字編輯器打開，全選複製，並貼上至此；或者選擇「由網址嵌入」（此法需將 HTML 檔案上傳至 Google Drive 並設定共用權限為「知道連結的任何人」）。
    5. 點擊「下一步」並確認「插入」。
    6. 拖曳調整區塊至適合大小，發佈即可！

## 3. 生成之學生端測驗網頁規格 (Generated Quiz specs)

### 3.1 視覺與介面 (UI/UX)
- **響應式設計 (RWD)**: 
  - **行動端排版優化 (<= 640px)**: 
    - 頂部導航 Bar 自動改為垂直單欄版面，確保科目、標題與語系切換按鈕不會因擁擠而重疊錯位。
    - 題目卡片左右外距與內距收窄（內距降至 `1.25rem`），保留更多螢幕寬度展示題目。
    - 題目字型微調為 `1.05rem`，選項與按鈕改為更易於大拇指點選的配置。
    - 操作按鈕（提交答案/下一題）改為 100% 寬度，提升觸控便利性。
    - 懸浮計分板尺寸微調收窄，防止遮擋作答視圖。
  - **防止觸控 Hover 粘滯**: 通過 `@media (hover: none)` 媒體查詢，在手機等不支援滑鼠懸停的觸控裝置上，重置 `:hover` 狀態的背景與邊框色。這能徹底修復點擊選項後「樣式粘滯、背景色一直亮著」的常見行動端網頁 UI Bug。
- **動態主題**: 依據產生器設定的主題色，動態渲染頂部 Bar、按鈕、選項 Hover 狀態、正確/錯誤狀態。
- **精美卡片式佈局**: 每題以獨立卡片展示，包含：
  - 題目序號與題目內文。
  - 4 個選項（Hover 時有平滑陰影與邊框變色微動畫，點選時有波紋效果）。
  - 「提交答案 / Submit」按鈕。
  - 回饋區（提交後顯示）：
    - **答對**: 顯示綠色背景與「正確！/ Correct!」標示。
    - **答錯**: 顯示紅色背景與「錯誤！/ Incorrect!」標示，並亮出正確答案。
    - **詳解**: 展示解析文字（如果 Excel 有輸入的話）。
- **中英雙語切換**:
  - 若為 Bilingual，在頂部 Bar 右側顯示「中 / EN」切換按鈕。
  - 點擊後，無縫切換：
    1. 題目與選項內容。
    2. 解析內容。
    3. UI 預設文字（例如：「第 X 題 / Question X」、「提交答案 / Submit」、「下一題 / Next」、「正確答案為 / Correct Answer is」）。

### 3.2 測驗功能與統計 (Quiz Mechanics)
- **大廳設定區 (Lobby Section)**:
  - 學生端開啟網頁後，會首先看見「大廳卡片」，展示練習標題、科目名稱與當前練習模式說明。
  - **姓名輸入框 (Student Name Input)**: 提示學生輸入姓名。在姓名輸入前，「開始作答 (Start)」按鈕為禁用 (disabled) 狀態。
  - 點選「開始作答」後，進入實際測驗畫面。
- **計分板 (Scoreboard)**: 
  - 測驗最下方顯示當前答題進度與得分（例如：「進度: 3 / 10 | 得分: 2」）。一題一頁模式與隨機抽題模式下答完自動更新。
  - 全部完成後，隱藏題目，顯示結算卡片。結算卡片上會動態渲染 **「[學生姓名] 同學」** 的結果，並提供 **「重新挑戰 / Retry」** 按鈕。
  - 點擊「重新挑戰」會清空作答記錄並返回大廳（保留上次輸入的姓名），若為「隨機抽 10 題」模式，重新挑戰會自動重新洗牌並隨機挑選 10 題。
- **防呆與即時保存**:
  - 已答題目會鎖定，無法重複提交，但解析會保持顯示。
  - 一題一頁或隨機抽題模式下，需提交當前題目，才會顯示「下一題 / Next」按鈕引導跳轉。
