# 功能規格書：非華語學生中文識字翻卡產生器 (Chinese Flashcard Generator for NCS)

本專案旨在為教師提供一個「中文識字翻卡網頁產生器」，專為非華語 (NCS) 學生學習中文漢字而設計。教師可以輸入中文單字與英文解釋，設定語音讀音（國語或粵語），一鍵編譯成一個獨立的 HTML 檔案，能輕鬆嵌入 Google Sites，提供 3D 翻轉卡片、國語/粵語語音朗讀、以及動態漢字筆劃動畫。

---

## 1. 核心需求與特點

### 1.1 純中文系統介面
* 配合學習中文的情境，教師端產生器與學生端學習介面的**所有系統標籤、按鈕、提示說明皆採用繁體中文（Chinese Only）**。
* 卡片背面為英文解釋（以利非華語學生理解），但系統控制元件（如「已學會」、「溫習中」、「上一張」、「下一張」、「開始溫習」、「讀音」、「筆劃」等）均為中文。

### 1.2 漢字筆劃動畫整合 (Hanzi Writer)
* **動畫繪製**：正面設有「✍️ 筆劃」按鈕，點擊後會呼叫 `Hanzi Writer` 庫，在卡片正面以動態 SVG 逐步繪製漢字的筆劃順序，幫助非華語學生練習書寫。
* **CDN 引入與離線降級**：
  - 連網時自 CDN (`https://cdn.jsdelivr.net/npm/hanzi-writer@3.5/dist/hanzi-writer.min.js`) 載入核心庫與字形數據。
  - 離線時（如偵測到載入失敗或 `HanziWriter` 未定義），筆劃按鈕將顯示靜態大字，並提示「筆劃動畫需要連接網路」。
* **筆劃色彩自適應**：筆劃的軌跡顏色會自動與所選的主題色彩聯動（如：科技藍主題下使用藍色筆劃）。

### 1.3 國語/粵語語音合成 (TTS)
* **讀音語系設定**：老師可在產生器中選擇發音為：
  - **國語/普通話** (`zh-CN` / `zh-TW`)
  - **粵語/廣東話** (`zh-HK`)
* **語音播放**：點擊「🔊 讀音」按鈕，調用 Web Speech API 對正面的漢字進行讀音朗讀。

### 1.4 TSV 解析規格
* 欄位格式：`漢字 <Tab> 英文解釋`。
* 漢字欄位只取第一個字（漢字筆劃動畫一次渲染一個字），若老師貼入詞彙，讀音仍會正常朗讀全詞，筆劃按鈕將預設顯示詞彙中第一個字的筆劃，並在旁邊提供字元切換或說明。為了操作的直觀與簡潔，建議以「漢字單字」為主。

## 2. 介面規格設計

### 2.1 教師產生器 UI (`generator.html`)
採用左右分欄或流暢的單欄區塊：
* **設定參數卡片**：
  - 科目名稱（預設：中文識字）
  - 練習標題（預設：第一課 漢字溫習）
  - 匯出檔案名稱（預設：chinese_flashcard_lesson1）
  - 讀音語系：下拉選單（`普通話/國語`、`廣東話/粵語`）
  - 主顏色調：下拉選單（科技藍、經典綠、活力橘、優雅紫）
* **題庫貼入卡片**：
  - 多行文字框，支援 Excel 兩欄複製貼上（A:漢字，B:英文解釋）。
  - 「載入範本」按鈕：載入基礎漢字與解釋範例（如：`山 \t mountain`, `水 \t water`）。
* **匯出與說明**：
  - 一鍵下載獨立 HTML 檔案。
  - Google Sites 嵌入指南。

### 2.2 學生自習 UI (`flashcard-template.html`)
* **大廳頁面**：
  - 顯示練習主題、科目與姓名輸入框，點擊「開始學習」進入。
* **翻卡舞台**：
  - **3D 雙面卡片**：
    - **正面 (Front)**：
      - 中文漢字（超大字體顯示）。
      - 浮動按鈕：「🔊 讀音」（Speak）及「✍️ 筆劃」（Strokes）。
      - 筆劃動畫框：點擊「筆劃」後，漢字文字隱藏，原位以 SVG 動態書寫漢字，並提供「重播筆劃」小按鈕。點擊空白處可還原回文字並可翻牌。
    - **背面 (Back)**：
      - 英文解釋。
  - **掌握度標記**：
    - 「👍 已學會」（綠色按鈕）
    - 「📖 溫習中」（橙色按鈕）
  - **切換與進度**：
    - 「上一張」、「下一張」按鈕，以及「卡片進度：X / Y」指示。
    - 自適應導航數字網格（綠色代表已學會，橙色代表溫習中，藍色代表當前）。
* **結算頁面**：
  - 顯示學生姓名、溫習時間、掌握率百分比圓環。
  - 詳細溫習回顧清單：依「已學會」與「需要溫習」分類排列，並可點擊播放漢字讀音。

## 3. 技術結構與檔案路徑

* 專案根目錄：`100_Todo/projects/chinese-flashcard-generator/`
* `src/flashcard.css`：學生端翻卡樣式表（含 3D 旋轉、Hanzi Writer 容器定位與動畫）。
* `src/flashcard.js`：學生端控制邏輯（含 Web Speech 國粵語判斷、Hanzi Writer 動態物件綁定、已學會統計）。
* `src/flashcard-template.html`：學生端頁面模板（內置 Hanzi Writer CDN 連結與降級策略）。
* `src/generator.html`：教師端純中文產生器網頁。
* `build.js` & `check.js`：打包合成器與 Node VM 語法校驗器。
* `README.md` & `report_record.md`：開發文檔與日誌。
