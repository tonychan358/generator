# 📝 Chinese Flashcard Generator (非華語學生中文識字翻卡產生器)

這是一個專為非華語 (NCS) 學生學習中文漢字設計的「中文識字翻卡產生器」。教師只需輸入漢字單字與英文解釋，設定讀音口音（普通話或廣東話）與主題配色，即可一鍵生成並匯出一個 **100% 離線可用、支持 RWD 手機版、內置漢字動態筆劃書寫動畫與國/粵語讀音** 的獨立 HTML 檔案，極易嵌入 Google Sites 中供學生進行自習認字與筆劃溫習。

## ✨ 特色功能
1. **教師端一鍵產生器**：
   - 全繁體中文親和介面，方便中文科教師操作。
   - 支援科目名稱、練習標題、匯出檔名自訂。
   - **讀音語系選擇**：可設定為**普通話/國語**或**廣東話/粵語**，事前鎖定。
   - 支援 Excel 漢字題庫直接貼入 (TSV 格式，欄位：A:漢字，B:英文解釋)。
   - 支援 4 種主題配色切換（科技藍、經典綠、活力橘、優雅紫）。
   
2. **學生端自習識字翻卡**：
   - **3D 翻轉卡片**：點擊卡牌即時進行 3D 翻面（正面漢字，背面英文解釋）。
   - **🔊 讀音按鈕**：點擊發音按鈕調用瀏覽器內置 API 進行中文國語/粵語朗讀，發音標準。
   - **✍️ 筆劃按鈕**：整合 `Hanzi Writer` 庫。點擊筆劃按鈕後，原漢字位置會被動態 SVG 書寫軌跡取代，一筆一劃動態畫出漢字的書寫順序，並配有田字格線背景與重新播放控制，極大利於 NCS 學生練習寫字。
   - **掌握度標記**：提供「👍 已學會」與「📖 溫習中」兩大標記，數據同步更新至下方導航網格與進度板中。
   - **詳細結算回顧**：結算頁面顯示學生姓名、溫習時間、掌握率，並分門別類排列「已學會」與「需要溫習」的漢字，附有語音播放按鈕，便於做最後溫習。
   - **離線防呆保護**：若使用者處於完全斷網狀態，筆劃按鈕將顯示靜態大字，並提示「筆劃動畫需要連接網路」，不影響基礎學習功能。

## 🛠️ 專案結構
- `src/flashcard.css`：學生端翻卡視覺樣式與 Hanzi Writer 田字格線佈局。
- `src/flashcard.js`：學生端翻卡邏輯、Web Speech 國粵語適配與 Hanzi Writer 動態書寫。
- `src/flashcard-template.html`：學生端測驗外殼模板。
- `src/generator.html`：教師端中文產生器介面與打包下載。
- `build.js`：Node.js 合成打包腳本。
- `check.js`：靜態語法測試。

## 🚀 執行方式
在專案目錄下執行以下指令以重新編譯合成 `index.html`：
```bash
node build.js
```
然後雙擊打開目錄下的 `index.html` 即可進入產生器。
