非華語學生中文識字翻卡產生器

非華語 (NCS) 學生中文漢字自習翻卡設計 - 內置國/粵語發音與 Hanzi Writer SVG 筆劃書寫動畫。

1 設定練習參數 / Configuration Settings

2 貼上漢字與英文解釋 / Paste Chinese Vocab

Excel 格式說明： 請在 Excel 中依序安排兩欄：A:中文漢字/詞彙(必填), B:英文解釋(選填，利於非華語生)。複製所有資料列（請勿包含標題列），直接貼上到上方區塊。（註：若字詞內含多個漢字，系統會自動在筆劃播放介面中生成字元標籤切換按鈕，供學生自由點選特定漢字檢視筆劃動畫）。

3 生成與匯出 / Export

產生器會將題庫與選定參數編譯入一個單一且離線可用的 HTML 檔案中。

Google Sites 嵌入步驟指引

1

輸入資料並下載檔案

設定科目名稱、練習標題、讀音口音（普通話/粵語），並貼上 Excel 複製之題庫後，點擊「下載獨立 HTML 檔案」。

2

複製 HTML 代碼

用電腦內建的「記事本」(Notepad) 開啟下載的 .html 檔案，按 Ctrl + A 全選，再按 Ctrl + C 複製全部內容。

3

在 Google Sites 新增全頁嵌入網頁

打開您的 Google Sites 協作平台編輯介面。在右側面板切換至「頁面」分頁，將滑鼠懸停在底部的「+」號上，點擊「新增全頁嵌入網頁」 ( 標籤)。

4

貼上 HTML 程式碼

輸入頁面名稱（如：中文識字）並點擊「完成」。在頁面中點擊「新增嵌入內容」，切換至「嵌入程式碼」分頁並貼入剛才複製的程式碼，點擊「下一步」並按「插入」。

5

發佈並與學生分享

全頁嵌入會自動 100% 填滿整個瀏覽器畫面，無需手動調整高度。最後點擊右上角的「發佈」按鈕，即可將網頁分享給學生！
