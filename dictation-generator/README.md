# 📝 Dictation Generator (英文自習默書產生器)

這是一個專為教師設計的「英文自習默書網頁產生器」。老師只需輸入該次默書的英文單字或句子（支援單字與句子模式），設定好標題與主題配色，即可一鍵生成並匯出一個 **100% 離線可用、支援 RWD 手機版、且內置 Web Speech API 語音朗讀** 的獨立 HTML 檔案，極易嵌入 Google Sites 中供學生進行自習默書與即時校對。

## ✨ 特色功能
1. **教師端一鍵產生器**：
   - 支援科目名稱、練習標題、匯出檔名自訂。
   - 支援兩種作答模式：**單字模式 (Vocab Mode)** 與 **句子模式 (Sentence Mode)**。
   - 內置預設語系切換（繁體中文、英文、雙語）。
   - 支援 Excel 題庫直接貼入 (TSV 格式，欄位：A:詞彙/句子, B:中文提示/中文翻譯(選填))。
   - 支援 4 種精緻主題配色切換（科技藍、經典綠、活力橘、優雅紫）。
   - **進階校對參數**：可設定是否「區分大小寫」及是否「忽略標點符號」，以便靈活滿足單字和句子的批改標準。

2. **學生端自習默書**：
   - 開始前引導學生在大廳輸入姓名。
   - 開始後題目自動進行 **隨機洗牌排序 (Shuffle)**。
   - **TTS 語音播放**：點擊發音按鈕呼叫瀏覽器內置的 Web Speech API 進行英文朗讀，離線可用且發音標準。
   - **分頁模式**：一題一頁，支援上一題、下一題，以及題號導覽網格，方便學生補默或檢查。
   - **答哂一次過校對**：默寫完畢後一次提交批改。系統會統計未答題數進行防呆警告。
   - **詳細校對回顧**：結算卡片顯示學生姓名、正確率，並在下方以卡片對比列出「正確答案」、「學生的回答」以及「紅綠對錯標記與發音按鈕」，方便覆習。

## 🛠️ 技術棧與架構
* **產生器架構**：採用模組化架構，將代碼職責分離：
  * `src/dictation.js`：學生端默書的核心邏輯。
  * `src/dictation.css`：學生端網頁的視覺樣式（支持觸控 `:hover` 粘滯優化與 RWD）。
  * `src/dictation-template.html`：學生端測驗外殼模板。
  * `src/generator.html`：產生器 UI 與解析 TSV、下載邏輯。
  * `build.js`：Node.js 合成腳本，將 `src/` 中的模組注入模板，轉義特殊標籤並生成最終的 `index.html`。
* **技術特點**：
  * 使用 HTML5 Web Speech API (`SpeechSynthesisUtterance`) 進行本地語音合成，不依賴任何外部 CDN 語音 API，完全零成本且支持完全無網離線執行。
  * 遵循 `export_html_generator_sop.md` 開發指南，確保變數轉義順序無 syntax 錯誤、無 CDN 依賴、完美 CORS 零限制。

## 🚀 執行方式
每次修改 `src/` 下的源碼後，在專案目錄下執行以下指令以重新編譯合成 `index.html`：
```bash
node build.js
```
然後雙擊打開根目錄下的 `index.html` 即可使用產生器。
