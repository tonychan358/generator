# 📋 Dictation Generator 技術規格說明書 (Technical Specification)

本專案旨在提供教師一個能快速將英文詞彙/句子轉為自習默書網頁的工具。生成的 HTML 必須具備 100% 離線可用性、RWD 手機端適配，並整合瀏覽器內建 Web Speech API 作為語音朗讀核心。

---

## 🛠️ 1. 產生器端規格 (Generator Specifications)

### 1.1 教師輸入參數
- **科目名稱 (Subject)**：例如 `English Dictation`、`S2 English`。
- **默書標題 (Dictation Title)**：例如 `Unit 3 Vocabulary`、`Ch.2 Dictation`。
- **自訂導出檔名 (Export File Name)**：默認由標題同步帶入，過濾非法字符。
- **默書模式 (Dictation Mode)**：
  - `vocab` (單字模式)：字幹一般較短，預設朗讀速度較快。
  - `sentence` (句子模式)：字幹較長，預設朗讀速度較慢，且預設批改忽略標點符號。
- **主題配色 (Theme Color)**：
  - `sky-blue` (科技藍)、`classic-green` (經典綠)、`vibrant-orange` (活力橘)、`elegant-purple` (優雅紫)。
- **語系模式 (Language Mode)**：
  - `zh` (繁體中文)、`en` (英文)、`bilingual` (中英切換)。
- **進階校對設定 (Grading Settings)**：
  - **區分大小寫 (Case Sensitive)**：勾選代表 `Apple` 與 `apple` 為不同答案；預設不勾選（Vocab 模式與 Sentence 模式皆為不區分大小寫）。
  - **忽略標點符號 (Ignore Punctuation)**：勾選代表批改時過濾兩邊及單字間常見的標點符號（如句號 `.`, 問號 `?`, 驚嘆號 `!`, 逗號 `,`）。Vocab 預設不勾選，Sentence 預設勾選。

### 1.2 題庫資料格式 (Excel/TSV)
欄位順序：`A:英文單字或句子` | `B:中文提示/中文翻譯(選填)`。
- 直接從 Excel 中框選複製，貼入產生器的文本區中。
- 資料行以 Tab 鍵分隔，行與行之間以換行符分隔。
- **防呆解析**：剔除空行，檢查每行是否至少包含第一欄英文。若英文欄為空則跳過，並給予警告。

## 🎧 2. 學生端默書網頁規格 (Student Dictation Web App)

### 2.1 大廳畫面 (Lobby)
- 輸入姓名以啟用「開始默書」按鈕。
- 顯示當次默書的主題、科目與模式標記。

### 2.2 默書答題畫面 (Dictation App)
- **分頁模式**：一題一頁。
- **題目發音**：
  - 核心採用 HTML5 內建 `speechSynthesis` API。
  - **發音參數**：
    - `lang`: `"en-US"` (美式英語) 或 `"en-GB"` (英式英語)，可提供切換選項（預設為 `"en-US"`）。
    - `rate` (朗讀速度)：單字模式預設為 `0.85`；句子模式預設為 `0.75`（使朗讀更清晰）。
  - 朗讀按鈕具有波紋微動畫，點擊觸發朗讀，可重複點擊。
- **答題輸入框**：
  - 學生輸入拼寫答案。
  - 支援對實體鍵盤的 `Enter` 鍵綁定：在輸入框按 `Enter` 自動跳轉到「下一題」。
- **中文提示區**：
  - 點擊「顯示提示 / Show Hint」可展開中文提示/翻譯（若老師有提供）。
- **題號導覽網格 (Navigation Grid)**：
  - 顯示所有題號（已答標記為灰色，未答為白色，當前題為高亮主題色）。
  - 支援手機直屏自適應折行，無 hover 粘滯。

### 2.3 提交防呆與校對邏輯 (Grading & Review)
- 當學生點擊「提交默書」時，統計未答題數，若有空題，彈出確認提示：`您還有 X 題未完成！`。
- **校對比對演算法**：
  1. 學生回答與正確答案去除兩端空白 (`.trim()`)。
  2. 若「忽略標點符號」開啟，將字串內的所有常見標點（`.` `,` `!` `?` `;` `:` `"` `'` `-`）替換為空字串，並把多個空白壓縮為單個空格。
  3. 若「區分大小寫」關閉，將比對字串一律轉為小寫 (`.toLowerCase()`)。
  4. 比對處理後的兩個字串是否完全一致。
- **結果結算畫面**：
  - 顯示學生姓名、正確率百分比、答對題數。
  - 提供評語反饋。
  - **自習回顧列表**：在結算卡片下方列出所有默書題。每一題展示：
    - 學生回答 vs 正確答案。
    - 若錯誤，用紅色標記並畫刪除線標記學生答案，綠色標記正確答案；若正確，綠色勾選。
    - 保留語音發音按鈕，方便學生進行二次聽寫溫習。

## 📦 3. 模組化打包與轉義規格 (Build & Escape)

遵循 `export_html_generator_sop.md` 開發指南，打包腳本必須：
1. 讀取 `src/dictation.css`、`src/dictation.js`、`src/dictation-template.html`。
2. 將 CSS 與 JS 合併寫入 HTML 模板。
3. 進行一次性安全轉義（反斜線 -> `\\\\`，重音符 -> `\\``，`${` -> `\\${`）。
4. **最後一步**：將 `/* {{DICT_TITLE}} */`、`/* {{THEME_PRIMARY}} */`、`/* {{QUESTIONS_DATA}} */`、以及 `'${langMode}'` (用單引號包覆) 等預留標記替換為未轉義的 JS 模板變數。
5. 將最終代碼注入產生器外殼的 `buildDictHTML` 函數中，並導出為根目錄下的 `index.html`。
