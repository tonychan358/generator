英文默書產生器

專為 Google Sites 設計的離線英文默書網頁產生器 - 支援網頁 TTS 語音朗讀，Excel 題庫一鍵轉換

1 設定練習參數 / Configuration Settings

2 貼上默書內容 / Dictation Material

Excel 匯入說明：請在 Excel 中準備兩欄：A欄: 英文單字/片語/句子 (必填), B欄: 中文提示/翻譯 (選填)。複製所有資料列（請勿包含標題列），直接貼上到上方區塊。

3 生成與匯出 / Export

產生器會將默書內容與設定編譯入一個單一且離線可用的 HTML 檔案中。

Google Sites 嵌入步驟指引

1

輸入資料並下載檔案

設定好本科科名、練習標題、默書模式、朗讀口音、配色，並貼上 Excel 複製之字詞後，點擊「下載獨立 HTML 檔案」取得 .html 檔。

2

複製 HTML 代碼

用電腦內置的「記事本」(Notepad) 或文字編輯器開啟下載的 .html 檔案，按下 Ctrl + A 全選，再按下 Ctrl + C 複製全部內容。

3

在 Google Sites 新增全頁嵌入網頁

打開您的 Google Sites 協作平台編輯介面。在右側面板切換至「頁面」分頁，將滑鼠懸停在底部的「+」號上，點擊「新增全頁嵌入網頁」 ( 標籤)。

4

貼上 HTML 程式碼

輸入頁面名稱（如：單字默書）並點擊「完成」。在頁面中點擊「新增嵌入內容」，切換至「嵌入程式碼」分頁並貼入剛才複製的程式碼，點擊「下一步」並按「插入」。

5

發佈並與學生分享

全頁嵌入會自動 100% 填滿整個瀏覽器畫面，無需手動調整高度。最後點擊右上角的「發佈」按鈕，即可將網頁分享給學生！
