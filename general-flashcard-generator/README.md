# 📝 General Flashcard Generator (通用跨學科翻卡溫習產生器)

這是一個專為各學科教師設計的**通用翻卡溫習網頁產生器 (General Flashcard Generator)**。教師可以完全自訂字卡的正面與背面欄位名稱、設定發音選項（國語、粵語、英語等或關閉）、選擇主題配色，並將題庫（TSV 格式）複製貼入，一鍵產生一個 **100% 離線可用、響應式 (RWD)、包含 Lobby 姓名登錄、3D 翻卡互動、TTS 語音朗讀、熟練度追蹤與 A4 橫向列印學習證書** 的單一獨立 HTML 檔案，極易嵌入 Google Sites 供學生自習。

## ✨ 特色功能

1. **教師端一鍵產生面板 (Teacher Dashboard)**:
   - **完全自訂欄位**: 老師可自由定義字卡「正面 (Front)」與「背面 (Back)」代表的內容名稱（例如：正面「漢字」/ 背面「粵語拼音」；正面「化學式」/ 背面「元素名稱」；正面「歷史事件」/ 背面「年份/人物」）。
   - **多語系 TTS 發音設定**: 支援設定發音語系（普通話、粵語、美式英語、英式英語，或關閉發音），並可指定朗讀卡牌的正面、背面或雙面皆可。
   - **初始卡面設定**: 學生開始時預設先看正面還是先看背面。
   - **Excel 題庫貼入 (TSV)**: 支援從 Excel/Google Sheets 複製兩欄數據後直接貼上。
   - **4 種精心調配的設計主題**: 科技藍、翡翠綠、朝陽橘、薰衣紫。
   - **Lobby 姓名輸入配置**: 自由開啟或關閉學生進入時的姓名輸入 Lobby。

2. **學生端自習複習介面 (Student revision)**:
   - **Lobby 學生登入**: 提供精緻的 Lobby 歡迎畫面，收集姓名以帶入證書。
   - **3D 翻轉互動**: 點擊卡片觸發精緻 3D 翻牌動畫（支援電腦與行動裝置防誤觸觸控）。
   - **適性發音 (TTS)**: 依老師設定，在卡片正面與/或背面顯示朗讀按鈕，點擊以 Web Speech API 本地發音。
   - **熟練度朗讀 (Mastery Track)**: 學生可標記「已掌握」與「溫習中」，狀態即時同步至下方導航網格。
   - **隨機洗牌 (Shuffle)**: 支援一鍵洗牌，隨機打亂卡片順序。
   - **A4 高保真橫向列印證書**: 結算畫面支援 A4 橫向列印（內建列印零邊距、Rem 比例放大與 Inset 陰影底色 Fallback 黑魔法）。

## 🛠️ 專案結構

- `src/flashcard.css`：學生端複習界面樣式與 3D 翻卡動畫。
- `src/flashcard.js`：學生端複習與 TTS 本地發音控制邏輯。
- `src/flashcard-template.html`：學生端 HTML 骨架與樣式注入區。
- `src/generator.html`：教師端通用配置面板。
- `build.js`：打包腳本，將 CSS/JS 內嵌壓縮至單一 `index.html`。
- `check.js`：沙箱語法檢查。

## 🚀 快速開始

在專案目錄下執行以下指令以編譯合成 `index.html`：
```bash
node build.js
```
然後雙擊打開 `index.html` 即可進入產生器。
