# 📝 規格書：通用跨學科翻卡溫習產生器 (General Flashcard Generator Specification)

本規格書定義了「通用跨學科翻卡溫習產生器 (General Flashcard Generator)」的系統架構、功能需求與設計規範。此產生器旨在幫助教師快速生成適用於任何科目的翻卡學習網頁，並支援高度自訂的卡牌欄位、TTS 本地語音播放、主題配色與 A4 高保真學習證書列印。

---

## 1. 核心需求與設計理念

### 1.1 跨學科通用性 (Cross-disciplinary & General-purpose)
- **欄位自訂**: 老師可自由定義字卡「正面 (Front Face)」與「背面 (Back Face)」的顯示名稱（例如：化學科可用「化學符號 / 元素名稱」、歷史科可用「歷史事件 / 發生年份」、中文科可用「生字 / 粵語拼音」）。
- **界面繁體中文支援**: 考量主要使用者為本地教師，教師端產生器以繁體中文顯示，而學生端複習界面則根據老師設定的欄位名稱自適應呈現。

### 1.2 100% 離線可用與單一 HTML 封裝 (Standalone & Offline-ready)
- **零外部框架依賴**: 學生端複習網頁必須為單一 HTML 檔案，不依賴任何外部前端框架（如 React/Vue）或外部 CSS/JS（除非有離線降級防呆）。所有樣式 (CSS) 與邏輯 (JS) 在打包時將會內嵌至最終的 `index.html`。
- **本地 Web Speech API**: 卡片發音功能完全基於瀏覽器內建的 `speechSynthesis` API，無需連接網路或使用任何外部語音 API。
- **SVG 圖示內聯**: 所有控制按鈕與圖示均使用內聯 SVG，保證離線時圖片資源不遺失。

### 1.3 題庫貼入與解析 (TSV Parsing)
- **解析模式**: 支援從 Excel 或 Google Sheets 複製兩欄數據後直接貼上，使用定位符（Tab 鍵，`\t`）進行欄位切換，解析為 `正面內容 \t 背面內容`。
- **異常防護**: 自動去除空白行、首尾空白字元，並在字卡為空時提供錯誤提示。

## 2. 功能規格與介面設計

### 2.1 教師端產生器介面 (`generator.html`)
教師端介面採用左右雙欄佈局：
* **左欄：配置與題庫輸入**
  * **基本資訊設定**:
    * 科目名稱 (Subject)
    * 練習標題 (Title)
    * 匯出檔案名稱 (Export Filename)
  * **字卡自訂設定**:
    * 正面欄位名稱 (e.g. 「漢字」、「單字」、「問題」)
    * 背面欄位名稱 (e.g. 「英文解釋」、「意思」、「答案」)
    * 初始卡牌朝向: 學生開始時預設先看「正面」或先看「背面」。
  * **發音選項 (TTS Setting)**:
    * 語系選擇: 關閉發音、廣東話/粵語 (`zh-HK`)、美式英語 (`en-US`)、英式英語 (`en-GB`)。
    * 發音卡面: 僅正面發音、僅背面發音、雙面皆可發音。
  * **視覺與輔助選項**:
    * 預設主題配色: 科技藍、翡翠綠、朝陽橘、薰衣紫。
    * 漢字田字格背景: 可選擇是否為卡片文字（若包含漢字）開啟田字格/米字格線背景。
    * 學生姓名收集 Lobby: 勾選是否開啟遊戲開始前的 Lobby 登入畫面。
  * **題庫貼入區域**:
    * 大文字框 (Textarea) 供教師直接貼入 Excel 的兩欄資料。
    * 提供「載入範例 (Load Example)」按鈕，快速帶入一組示範數據（如化學式與元素名稱對應）。
* **右欄：匯出與 Google Sites 嵌入指南**
  * **產生並下載**: 點擊按鈕，動態將教師配置與題庫編譯打包，觸發瀏覽器下載單一的 `.html` 檔案。
  - **嵌入說明**: 提供複製代碼與在 Google Sites 中嵌入的逐步指南。

### 2.2 學生端複習介面 (`flashcard-template.html` / `flashcard.js`)
* **Lobby 歡迎畫面 (若開啟)**:
  * 顯示科目與標題。
  - 學生姓名輸入框（通過防空驗證）。
  - 「開始溫習」按鈕。
* **複習主畫面 (Flashcard Arena)**:
  - **3D 雙面翻牌卡片**:
    - 使用 CSS 3D Transforms (`perspective`, `rotateY`, `backface-visibility: hidden`) 實現流暢的 3D 翻轉。
    - 點擊卡牌的任意區域（或點擊下方「翻轉」按鈕）可使卡片做 3D 翻面。
    - 卡片正面與背面根據教師設定的發音選項，在角落顯示喇讀圖示。點擊喇叭即呼叫 `window.speechSynthesis` 播放該卡面文字。
  - **熟練度標記**:
    - **「我已學會 / Mastered」** (綠色勾): 標記卡片為已學會。
    - **「仍需溫習 / Need Review」** (橘色循環): 標記卡片需再溫習。
  - **進度控制與統計**:
    - 「上一張」與「下一張」按鈕，配合「隨機洗牌 (Shuffle)」功能。
    - **進度條與數據板**: 顯示當前進度（如 `卡片 3 / 10`）與統計數據（`已學會: X | 溫習中: Y`）。
    - **導航網格 (Navigation Grid)**: 顯示所有卡片編號按鈕，顏色對應其標記狀態（灰-未標記、綠-已學會、黃-溫習中）。點擊網格編號可快速跳轉卡片。
* **複習結算與 A4 證書列印**:
  - 顯示學生姓名、溫習總時間、已學會比例。
  - 將卡片依狀態分類列出（已學會清單、需要溫習清單），並在清單旁保留發音按鈕。
  - **列印榮譽證書**: 點擊「列印證書」按鈕，觸發 A4 橫向高保真列印：
    - 強制套用 `size: landscape; margin: 0;`。
    - 使用 `box-shadow` 的 inset 屬性作為 100% 完美的背景色彩列印 Fallback，防止瀏覽器變白。
    - 根字型 Rem 縮放，將預覽證書等比例放大至實體 A4 寬高 (297mm x 210mm)，移除邊框圓角以貼合紙張。

## 3. 目錄與檔案配置

- 專案目錄: `100_Todo/projects/general-flashcard-generator/`
- 開發源代碼:
  - `src/flashcard.css` (學生端樣式與 3D 翻轉效果)
  - `src/flashcard.js` (學生端複習流、洗牌與 Web Speech API 語音朗讀邏輯)
  - `src/flashcard-template.html` (學生端 HTML 骨架與樣式替換標記)
  - `src/generator.html` (教師端產生面板)
- 打包建置:
  - `build.js` (合併 JS、CSS、模板及題庫並壓縮輸出)
  - `check.js` (靜態語法語氣校對)
  - `index.html` (編譯產生之最終單一網頁成品)
